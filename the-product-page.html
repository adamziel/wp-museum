Sideways through time

Every era
left a mark.

2003 · fork

The branch that kept going.

b2/cafelog stalled; WordPress became the fork with momentum, comments, permalinks, and a public roadmap.

2005 · themes

Design became swappable.

Content and presentation split apart. A new look stopped requiring a rebuild.

2008 · admin

The dashboard grew up.

Drag modules. QuickPress. One-click updates. WordPress started maintaining itself.

2016 · REST API

Every site became data.

Posts, pages, media and users could travel as JSON to apps, kiosks, and anything with a fetch call.

2018 · blocks

The page became pieces.

Gutenberg made every paragraph, image and button movable, remixable, and programmable.

Today · site editing

The template is editable.

Headers, footers, styles, patterns: the whole site moved into the browser.

The editor

Blocks.
Stack 'em high.

Headings, galleries, columns, buttons — every piece of a page is a block you can move, restyle and reuse. Writing became building, and the page became the canvas.
